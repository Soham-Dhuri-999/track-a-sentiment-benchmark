# Track A — LLM Sentiment Benchmarking Study

A systematic comparison of 5 NLP models on Twitter sentiment classification,
ranging from rule-based baselines to large language models.

---

## Hypothesis

RoBERTa (tweet-trained) will outperform distilBERT and VADER on social media
sentiment because domain alignment matters more than model size.

**Result: Hypothesis rejected.** Zero-shot LLMs outperformed all fine-tuned
transformers, with Gemini 2.0 Flash achieving the highest F1 of 0.80.

---

## Models Benchmarked

| Model | Type | Infrastructure |
|---|---|---|
| VADER | Rule-based baseline | Local |
| distilBERT | Fine-tuned transformer (SST-2) | HuggingFace |
| RoBERTa | Fine-tuned transformer (Twitter) | HuggingFace |
| LLaMA 3.1 8B | Zero-shot LLM | Groq API |
| Gemini 2.0 Flash | Zero-shot LLM | OpenRouter API |

---

## Dataset

Sentiment140 — 1.6M tweets
- VADER, distilBERT, RoBERTa: 10,000-row stratified sample (5K positive, 5K negative)
- LLaMA, Gemini: 500-row subsample (256 positive, 244 negative) due to API rate limits

---

## Results

| Model | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| VADER | 0.6530 | 0.6646 | 0.6178 | 0.6403 |
| distilBERT | 0.7093 | 0.7568 | 0.6168 | 0.6797 |
| RoBERTa | 0.7103 | 0.7775 | 0.5892 | 0.6704 |
| LLaMA 3.1 8B | 0.7660 | 0.7791 | 0.7578 | 0.7683 |
| Gemini 2.0 Flash | 0.7920 | 0.7879 | 0.8125 | **0.8000** |

---

## Key Findings

1. **Zero-shot LLMs beat fine-tuned transformers.** LLaMA and Gemini outperformed
   both distilBERT and RoBERTa without any task-specific training — suggesting
   that scale and instruction-following ability compensate for lack of fine-tuning.

2. **Hypothesis rejected.** RoBERTa's Twitter-domain fine-tuning did not produce
   better F1 than distilBERT, and both were surpassed by zero-shot LLMs.

3. **Recall gap in transformers.** distilBERT (0.617) and RoBERTa (0.589) show
   notably low recall — they miss a significant portion of positive tweets.
   LLMs don't have this problem (LLaMA: 0.758, Gemini: 0.813).

## Architecture
```
Sentiment140 (1.6M tweets)
        ↓
Stratified 10K sample
        ↓
┌─────────────┬──────────────┬──────────────┬─────────────┬──────────────┐
│    VADER    │  distilBERT  │   RoBERTa    │    LLaMA    │    Gemini    │
│ rule-based  │  HuggingFace │  HuggingFace │  Groq API   │  OpenRouter  │
└─────────────┴──────────────┴──────────────┴─────────────┴──────────────┘
        ↓
metrics.csv + visualize.py → 3 comparison charts
```

---

## How to Run
```bash
pip install -r requirements.txt

# Set API keys (PowerShell)
$env:GROQ_API_KEY = "your_groq_key"
$env:OPENROUTER_API_KEY = "your_openrouter_key"

python benchmark.py
python visualize.py
```

Skip logic is built in — completed model runs are not re-executed.
